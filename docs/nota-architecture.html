02 — Агенты
🔴
Артём
Охотник за трендами в соцсетях
Мониторит соцсети: что хайпует в США, Европе, Китае прямо сейчас. Ищет новые форматы продуктов, вирусные категории, контент от инфлюенсеров в сфере FMCG.
Источники данных
X / Twitter (Grok) TikTok (Exa) LinkedIn (Exa) YouTube (Exa) Instagram (Exa)
Технический стек
Grok API (xAI) — X/Twitter реальное время
Exa.ai — нейропоиск по соцсетям
Python функция search_social()
🔵
Вова
Аналитик официального FMCG рынка
Шерстит официальные источники: отраслевые отчёты, Nielsen, Euromonitor, Forbes, FoodNavigator. Даёт цифры, доли рынка, официальную аналитику по категориям.
Источники данных
Nielsen (Exa) Euromonitor (Exa) FoodNavigator (Exa) Forbes (Exa) Mintel (Exa)
Технический стек
Exa.ai EN — семантический поиск
Domain filtering (site: параметр)
Python функция search_fmcg_web()
🟡
Петя
Компаратор трендов Запад vs Россия
Находит что уже взлетело на Западе и проверяет — есть ли это в России. Ищет «белые пятна» — ниши где спрос есть, а предложения нет. Главный поставщик идей для запуска.
Источники данных
Exa RU + EN Яндекс (через Exa) Google Trends (Exa) ТАСС / РБК (Exa)
Технический стек
Exa.ai RU — русскоязычный поиск
Exa.ai EN — параллельный поиск
Python функция compare_trends()
🟣
ЯмакасиТудаси
Маркетолог-упаковщик под рынок РФ
Берёт сырую идею и думает как её продать в России. Знает все твои NOTы, предлагает форматы, ЦА, каналы, упаковку, ценообразование. Всегда доступен для диалога в Telegram.
Источники данных
Supabase NOTы note_reports История диалога Claude Memory
Технический стек
Claude claude-sonnet — анализ и генерация
Supabase — контекст всех NOTы
Message history — память чата
🟢
Чукча
Оркестратор — мозг системы
Принимает твой вопрос, решает каких агентов запустить, запускает параллельно, ждёт результаты, синтезирует один связный ответ и отправляет тебе.
Что умеет
Роутинг запроса → нужным агентам
Параллельный запуск агентов
Синтез результатов в один ответ
Еженедельный авто-дайджест
Сохранение находок → Supabase
Управление памятью диалога
Технический стек
Claude claude-sonnet (tool_use)
Anthropic SDK — Python
python-telegram-bot 20+
Supabase — хранение результатов
Railway / VPS — хостинг бота

3
